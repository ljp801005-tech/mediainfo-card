# MediaInfo 媒体信息卡片

> 把 PT 种子详情页里那一大坨 MediaInfo 英文原文、以及原盘的 BDInfo 碟报，整理成和站点同款的「媒体信息」行——一眼看清码率、分辨率、音轨、字幕，还能一键复制成整理好的文本。

**当前版本：v1.11.2　｜　适用站点：16 个 PT 站（HDChina / HDHome / HHanClub / OurBits / PTer / KeepFRDS / U2 / TLF / TTG / CHDBits / M-Team / FileList / HTPT / BTN 等，另有 2 站按站方要求不点名，详见第四节）**

---

## 一、解决什么问题

PT 的种子详情页，MediaInfo 基本都是这样出现的：

- 几十行英文原文，挤在「简介」里或者一个折叠块里，要点开、要往下翻；
- 关键信息（体积、时长、分辨率、视频/音频编码与码率、字幕语种）散落各处，找起来费劲；
- 想复制成整理好的格式发给别人，得手工删一堆无关字段。

这个小脚本会自动找到页面上的 MediaInfo 或 BDInfo（**包括 `display:none` 折叠起来的、`<textarea>` 里的、用 `<br>` 逐行排版的**），解析成结构化字段，直接插在「简介」上方作为一行常驻信息，不必展开简介也能看到。

## 二、效果

（此处贴 `preview-mediainfo-card-v1.7.3-disc-title.png`：原盘 BDInfo 被包在「引用」框里、卡片仍落在「简介」上方；div 布局站点可另贴 `preview-mediainfo-card-v1.8.0-mteam.png`，短格式原盘可另贴 `preview-mediainfo-card-v1.7.0-BDInfo.png`，重编码种子可另贴 `preview-mediainfo-card-v1.6.3.png`）

- 位置：作为表格里独立的一行，位于「简介」上方，左侧有和「字幕」「简介」同款的「媒体信息」标签格；
- 样式：没有白底卡片、没有阴影、没有彩色色条，字体/字号/正文色/字段名色/分隔线全部从站点自身样式采样，看起来就是站点原生的表格行；
- 内容（重编码）：文件名 / 日期 / 体积 / 时长 / 帧率 / 参数 / 分辨率 / 视频 / 音频 / 字幕，短字段并排、长字段独占一行，列数随可用宽度自适应；
- 内容（原盘 BDInfo）：碟名 / 标签 / 体积（正片·整盘）/ 播放列表 / 时长 / 总码率 / 帧率 / 分辨率 / 视频 / 音频 / 字幕。

## 三、功能

| 功能 | 说明 |
| --- | --- |
| 自动识别 | 按内容特征打分识别，不依赖具体模板类名；折叠/隐藏/textarea/`<br>` 排版都能读到 |
| 原盘 BDInfo | 重编码种子看 MediaInfo，原盘碟报看 BDInfo：`Disc Title` / `Disc Size` / `Playlist` / `Total Bitrate` 与各条 `Video`、`Audio`、`Subtitle` 都能解析，短格式与 BDInfo 导出的分段表格长格式都认；字节数自动换算 GiB，`Length` 转成 `1h 48min 56s` |
| 结构化展示 | 字段顺序、全角对齐标签与你常见的整理格式一致；短字段自动并排，长内容跨整行 |
| 一键复制 | 「复制」输出 `文件名／日期／体积／时长／…／字幕` 的纯文本，可直接贴到论坛、聊天、Notion |
| 融入站点样式 | 内嵌时从「简介」行采样字体、字号、正文色、次要色、边框色，深色站点也自动跟随 |
| 悬浮 / 内嵌 | 默认智能：能找到「简介」行就内嵌；找不到就右下角悬浮（可拖拽，位置会记住） |
| 多份切换 | 一个页面有多份 MediaInfo 时，用 `‹ 1/2 ›` 切换 |
| 查看原文 | 「原文」按钮展开原始 MediaInfo，不用去翻页面 |
| 参数折叠 | x264/x265 编码参数默认只显示关键几项，点「+ 全部 N 项」看完整 |
| 字幕折叠 | 字幕超过 5 条时只列出中 / 英文字幕，其余收进「+ 更多（N）」，点击展开全部；复制与原文仍完整 |
| 快捷键 | `Alt + M` 显示 / 隐藏 |
| 版本自检 | 每 24 小时查一次新版（只读脚本头里的版本号），有新版本时版本号右侧亮红点，点红点即更新；查过的时间会缓存，不会每次开页面都联网 |
| 菜单集成 | 油猴菜单：显隐、切悬浮/内嵌、恢复智能定位、重置位置、重新扫描、检查新版本、关于/版本 |
| 版本面板 | 点标题行右侧 `v1.11.2` 查看版本、更新状态、当前站点、卡片落位、生效范围与更新记录 |

## 四、安装

1. 浏览器装好 **Tampermonkey**（Violentmonkey 同样可用）；
2. 油猴面板 → 「添加新脚本」，把 `mediainfo-card.user.js` 全文粘贴进去保存；或者直接把 `.user.js` 文件拖进浏览器扩展页；
3. 打开任意种子详情页即可，页面没有 MediaInfo 时脚本不做任何改动。

**不想装油猴？** 同一份代码也打包成了 Chrome 扩展：到 Releases 下载 `mediainfo-card-extension.zip`，解压到固定位置，`chrome://extensions/` 打开「开发者模式」→「加载已解压的扩展程序」选中那个文件夹即可。功能一模一样，只是菜单从油猴菜单换到了浏览器工具栏图标上；Edge 等 Chromium 内核浏览器同理（`edge://extensions/`）。扩展不收集任何数据，唯一的外部请求是每 24 小时读一次版本号。

> 发种 / 编辑页（`upload.php`、`edit.php`、`takeupload.php`）默认不启用，这几页的 MediaInfo 要贴进输入框提交，插入卡片反而添乱。

> **已适配的站点**（`@match` 里都写好了，装完即用）：HDChina 瓷器、HDHome、HHanClub、OurBits、PTer、KeepFRDS、U2、TLF、TTG、CHDBits、M-Team、FileList、HTPT、BTN；另有 2 个站按站方要求不点名，适配与上面这些完全一样。为免打扰站方，这里不写站点域名的明文（下面示例用 `example.com`），真实地址见脚本头部 `@match`。
>
> **想加新站**：头部补两行 `@match`（裸域 + `*.域`），再在 `SITES` 里登记一行名字。例如
> ```js
> // @match  *://example.com/*
> // @match  *://*.example.com/*
> ```
> 结构特殊的站点，在同一行 `SITES` 的 `desc` 里补一条容器线索（如 `.markdown-body`），落位就会更准。

## 五、使用

标题行右侧的按钮从左到右：

`复制` `原文` `定位` `悬浮/内嵌` `主题·自动` `▾`（折叠） `×`（收成悬浮球） `v1.11.2`

- **复制**：把当前这份信息复制成整理好的纯文本；
- **原文**：展开/收起 MediaInfo 原文；
- **定位**：滚动到页面上的「简介」区块并短暂高亮；
- **悬浮/内嵌**：手动切换位置，选择会记住；
- **主题·自动**：自动 / 亮色 / 暗色循环切换（内嵌时自动跟随站点配色，一般不用管）。
- **字幕折叠**：字幕超过 5 条时，小语种字幕会收在「+ 更多（N）」里，点开可看全部。
- **版本号（右侧）**：点开看版本信息；如果它右边多了个**小红点**，说明仓库里有新版本，点红点即可更新。

## 六、配置项（脚本内 `CONFIG`）

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| `mode` | `'auto'` | `auto` 智能 / `float` 始终悬浮 / `inline` 始终内嵌 |
| `theme` | `'auto'` | 自动 / `light` / `dark` |
| `insertPosition` | `'above-intro'` | 作为独立行放到「简介」上方；`before-mediainfo` 为旧行为 |
| `inlineMinCol` | `340` | 内嵌时每列最小宽度，调大列数变少 |
| `gridMinCol` | `300` | 悬浮卡片每列最小宽度 |
| `followSiteStyle` | `true` | 是否采样站点配色/字体来融入页面 |
| `paramLimit` | `8` | 「参数」默认显示几项 |
| `subtitleCollapseThreshold` | `5` | 字幕超过几条时折叠；`0` 关闭 |
| `subtitleKeepLangs` | `['zh', 'en']` | 折叠时保留的语言分组 |
| `excludePaths` | `['/edit.php', '/upload.php']` | 这些路径完全不启用 |
| `maxInfo` | `12` | 单页最多处理几份 MediaInfo |
| `onlyTorrentDetail` | `false` | `true` 时只在详情页 URL 运行 |
| `extraSelectors` | 若干 PT 常见容器 | 站点容器特殊时往这里补选择器 |
| `descriptionSelectors` | 若干简介容器 | 非表格布局时用来定位简介区块 |
| `excludeHosts` | `[]` | 不想生效的域名 |

## 七、大致原理

1. **识别**：遍历页面元素，对文本按「是否像 MediaInfo / BDInfo」打分（`General` 段头、`Complete name`、`File size`、`Encoding settings`、`Disc Title` / `Disc Size` / `.MPLS` / `Total Bitrate`、或已整理好的中文格式等），分数够高才算，优先取最小最具体的容器，避免把整页当成 MediaInfo；
2. **解析**：分段解析 `General/Video/Audio/Text`，格式化成中文整理格式（码率、声道、语种、字幕标题去重等）；原盘 BDInfo 先收 `Key: value`、再解析 `VIDEO / AUDIO / SUBTITLES` 分段表格，两路归一后输出原盘字段组；
3. **落位**：找到「简介」所在的 `<tr>`，克隆它的标签格和内容格，构造一行「媒体信息」插在它上方；非表格布局则插到简介容器之前；都找不到就悬浮；
4. **配色**：从「简介」内容格取字体/字号/正文色，从标签格取次要色，从表格边框取分隔线色（并校验与底色的对比度），写成 CSS 变量；
5. **异步兼容**：`MutationObserver` + 延迟重扫，站点异步渲染或点开「展开 MediaInfo」后会自动更新。

## 八、更新记录

**v1.11.2** 修了两类实际页面上撞到的问题：MediaInfo 的「原始参数名」写法（`CompleteName` / `FileSize/String` / `Format_Version`）以前认不出来、卡片整块不出；「复制诊断信息」被浏览器拦下时不再谎报成功，改为弹出可全选的文本框。另外原文收起后不再在表格里留一行空「简　介」，诊断新增「卡片」一行（已渲染几行字段 / 多大尺寸）。

## 九、常见问题

**Q：装好了但页面没反应？**
先确认地址在第四节列出的站点清单里（没列的站要自己加 `@match`）。另外确认这一页真的有 MediaInfo 文本；有卡片但位置或字段不对时点「诊断」，里面会写明站点、落位方式与每个字段的解析结果。

**Q：卡片跑到右下角去了，没有插在简介上方？**
说明没找到「简介」所在的行。把 `CONFIG.descriptionSelectors` 里补上站点简介容器的选择器，或者把那段 HTML 贴给我，我按真实结构加进去。

**Q：颜色 / 字体跟站点还是有点不一样？**
内嵌样式是从「简介」那一行采样的，如果站点用图片或特殊皮肤，可能取不到合适的值。可在 `CONFIG` 里把 `followSiteStyle` 设为 `false`，用脚本自带的浅色/深色样式。

**Q：只想看完整参数？**
点「参数」后面的「+ 全部 N 项」，或点「原文」。

**Q：能支持我用的站吗？**
能，改 `@match` 先试；NexusPHP/Unit3D/Gazelle 系一般直接可用。位置或样式不对，给我站点名 + 详情页 HTML 片段，我调选择器。

## 十、已知限制

- 只识别**文本形式**的 MediaInfo；如果是截图或图片，无法识别；
- 位置优化优先照顾表格布局的详情页（NexusPHP 系），div 布局（M-Team / FileList）走「区块前插入」，不会对齐到「简介」标签列；
- 站点改版导致容器变化时，可能需要更新 `extraSelectors` / `descriptionSelectors`；
- 需要页面本身能读到 MediaInfo 文本（例如登录后才显示的内容，得先登录）。

## 十一、反馈

遇到问题请附上：**站点名 + 页面 URL 结构（可脱敏）+ 截图 + 那段 HTML 片段**。这样定位最快。也欢迎提需求，比如字段顺序、想加的字段（HDR/杜比视界/音轨语言标记等）。
